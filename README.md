## ✦ Overview

Rama Studio is an independent creative studio portfolio showcasing original conceptual studies, illustration systems, campaign art, and brand direction packages.

### Key Sections & Features:
- **Hero & Manifesto:** Kinetic typography, custom cursor, and dynamic 3D-inspired knot sculpture visual.
- **Selected Work (Case Studies):** Deep-dive modal views featuring concept background, creative direction, process breakdown, and artwork specs.
- **The Open Studio (Gallery):** Categorized artwork filter (Illustration, Drawing, Social, Commercial, Personal) with full-screen lightbox viewer.
- **Process Comparison:** Interactive split-screen slider comparing rough sketches to finished botanical illustrations.
- **Intuition with Intention:** Interactive 5-step creative process roadmap with dynamic visual previews.
- **Art That Performs:** Horizontal drag-and-scroll social campaign directions and reel covers.
- **Services Showcase:** Interactive service explorer with real-time responsive previews.
- **Investment Architecture (Pricing):** 
  - **Brand Packages (Tiers 01–05):** From Brand Starter (₹5,000) to Complete Brand System (₹25,000).
  - **Creative Retainer:** Ongoing monthly creative direction & management (₹60,000/mo).
  - **The Sketchbook:** 12 bespoke artwork & commission categories.
- **Interactive Project Inquiry:** 4-step client brief builder with validation and offline brief export.

## ✦ Running Locally

To run the site locally on your machine:

```bash
cd "rama studio/dist"
python3 -m http.server 8080
```

Then visit `http://localhost:8080` in your web browser.
